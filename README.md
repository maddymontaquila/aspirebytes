# Aspire Bytes

Small sample apps used in Aspire Bytes videos.

## Setup

Follow instructions on [get.aspire.dev](get.aspire.dev) to install the Aspire CLI. For each sample, there may be other requirements such as:

- A container runtime (Docker, Podman, etc)
- A specific programming language or cli (Python, Node, .NET, etc)
- Provisionable cloud enviornment (Azure, AWS, etc)
